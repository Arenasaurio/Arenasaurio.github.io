# Portafolio Frutiger Aero - César Eduardo Arenas Sánchez

Este es el portafolio personal de César Eduardo Arenas Sánchez, Data Scientist & Machine Learning Engineer, diseñado con una estética **Frutiger Aero** (estilo Windows Vista/7).

## Estructura del Proyecto

- `index.html`: Archivo principal con la estructura HTML5 y clases de Bootstrap 5.
- `css/style.css`: Estilos personalizados para lograr el efecto "glassmorphism", gradientes y brillos característicos de Frutiger Aero.
- `js/script.js`: Scripts para animaciones de entrada y efectos interactivos.
- `assets/`: Directorio para imágenes e iconos.

## Tecnologías Usadas

- **HTML5 Semántico**
- **Bootstrap 5.3** (Framework base)
- **CSS3** (Variables, Gradientes, Animaciones, Backdrop-filter)
- **JavaScript (Vanilla)** (Intersection Observer para animaciones)

## Cómo ver el portafolio

Simplemente abre el archivo `index.html` en tu navegador web favorito.

## Personalización

Para cambiar la imagen de fondo o la foto de perfil, reemplaza los archivos en la carpeta `assets/` o actualiza las rutas en `css/style.css` y `index.html`.
